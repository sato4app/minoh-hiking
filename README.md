## minoh-hiking - 箕面でハイキング - ハイキング・ナビ

### 実装機能

#### 初期画面

  - 初期画面(png)を表示
  - 画面の右側中央部に、以下のボタン(textは右寄せ)を縦に並べて表示
    * ハイキングマップ表示
    * ハイキングコース案内・ナビ
    * コース分岐路等のデータ収集
    * 設定
	  - トグル: 詳細データをダウンロード
              Off:z=10～17、On:z=10～18
	  - ボタン: オフライン用地図データをダウンロード
	  - ボタン: ダウンロードした地図データをクリア
    - ボタン: メッセージ履歴を表示

#### 共通機能

  - PWAサポート
  - 地理院地図を初期表示
  - 箕面緊急ポイント(約170点)と公式ハイキングコースを表示
  - オフライン対応用に地理院地図データを事前にダウンロード可能

### 当面実装の対象外

#### ハイキングコースの表示

  - 現在位置の表示

#### ハイキングのコース案内・ナビ

  - コース選択（起点・終点の指定、おすすめコースから選択）

#### コース分岐路等のデータ収集

  - 移動の経路をGPS記録
  - 経路や写真は、スマホ(indexedDB)に一時的に保存
  - 保存データはcloud databaseに保存
