## minoh-hiking - 箕面でハイキング - ハイキング・ナビ

### 実装機能

#### 初期画面

  - 初期画面(png)を表示
  - 画面の右側中央部に、以下のボタン(textは右寄せ)を縦に並べて表示
    * ハイキングマップ表示
    * ハイキングコース案内・ナビ
    * コース分岐路等のデータ収集
    * 設定
	  - トグル: 詳細データをダウンロード
              Off:z=10～17、On:z=10～18
	  - ボタン: オフライン用地図データをダウンロード
	  - ボタン: ダウンロードした地図データをクリア
    - ボタン: メッセージ履歴を表示

#### 共通機能

  - PWAサポート
  - 地理院地図を初期表示
  - 箕面緊急ポイント(約170点)と公式ハイキングコースを表示
  - オフライン対応用に地理院地図データを事前にダウンロード可能
  - 通行止め・通行困難地点を表示(公開API `/api/closures` から取得。
    オフライン時は Service Worker の `closures-cache` が最終取得内容を返す)

#### 通行止め・通行困難地点の公開API

  本アプリは通行止め・通行困難地点を**表示するだけ**で、登録・公開の機能は持たない。

  - 公開API(`api/closures.js` + Vercel Blob)は本リポジトリが提供する。
    本アプリは `GET /api/closures` で取得し、`POST /api/closures`(公開)は
    **外部の運用アプリ**(別リポジトリ)が呼ぶ。
  - API の契約(エンドポイント・認証ヘッダ・応答)は
    [設計書 §5](docs-closures/closures-design-202607.md)を正本とする(契約バージョン 1.0)。
    検証・応答を変えるときは契約バージョンを更新し、呼び出し側にも反映すること。

### 当面実装の対象外

#### ハイキングコースの表示

  - 現在位置の表示

#### ハイキングのコース案内・ナビ

  - コース選択（起点・終点の指定、おすすめコースから選択）

#### コース分岐路等のデータ収集

  - 移動の経路をGPS記録
  - 経路や写真は、スマホ(indexedDB)に一時的に保存
  - 保存データはcloud databaseに保存
