## minoh-hiking - 箕面ハイキングマップ

### 概要

大阪府箕面市のハイキングマップを、国土地理院地図の上に表示し、
現在地とあわせて表示するWebアプリ

### 実装機能

#### 初期画面

  - 初期画面(webp)を表示
  - 画面の右側中央部に、以下のボタン(textは右寄せ)を縦に並べて表示
    * QR
      - いま開いているページのURLをQRコードで表示
    * ハイキングマップ表示
    * 地図データのダウンロード
	  - 表示: サイズ（z=14～17 の概算。一部取得済みなら更新分も）
	  - トグル: 詳細地図(z=18)を含む（Off:z=14～17、On:z=14～18）… 現在は非表示で z=14～17 のみ。
	    config.js の DOWNLOAD_DETAIL_ENABLED を true にすると復活する
	  - ボタン: ダウンロード（地理院地図タイルのダウンロード）
	  - ボタン: クリア（ダウンロードした地図データをクリア）
    * 設定・情報/Settings & Info
    - トグル: ご利用の注意とよくある質問（注意9項目と、よくある質問26問。質問をタップすると答えが開く）
    - トグル: メッセージ履歴の表示
    - トグル: バージョン情報（On でアプリ・地図・通行止めのバージョンとデータ件数を表示）
    - トグル: このアプリについて（アプリ名・URL・ソースコード・Credits）
    - ボタン: マーカーの設定
    - ドロップダウンリスト: 言語の設定/Language Settings
    * 使い方
      - アプリの使い方を1ページずつ案内(説明する場所だけを明るく残して表示)
      - ページに応じて起動時画面とハイキングマップ表示を行き来し、閉じると元の画面に戻る
      - 初回起動時は自動で表示。以降はこのボタンから何度でも開ける
  - いずれかのボタンをタップすると、アプリの更新版を確認(新しい版があれば更新するか尋ねる)

#### 共通機能

  - PWAサポート
  - 地理院地図を初期表示
  - 箕面緊急ポイント(約170点)と公式ハイキングコースを表示
  - 通行止め・通行困難地点を表示
  - オフライン対応用に地理院地図タイルを事前にダウンロード可能
  - 地図の右下に、下から順に 国土地理院クレジット・縮尺・ズームレベル・ズーム(＋/−)・現在地点表示ボタン を配置
    * 現在地点表示ボタン（メニューの「現在地点をマーカー表示」とは独立した単発の操作）
      - タップで青丸・精度円を表示し、現在地点を画面中央へ移動。3秒で消えて灰色に戻る
      - 移動経路の記録中も表示する

#### メニューボタン

  ハイキングマップ表示中、画面右上のメニューボタン(≡)で表示設定パネルを開く。
  以下を表示・実行できる。

    * トグル: 時刻を表示 (既定 On)
      - メニューボタン(≡)の左に現在時刻(時:分)を表示
    * トグル: ズームレベルを表示 (既定 On)
      - 画面右下に現在のズーム(z=NN)を表示
    * トグル: 現在地点をマーカー表示 (既定 On)
      - 現在地マーカー(青丸)を表示。移動経路の記録中も表示する
      - On にすると精度円を3秒間だけ表示
    * トグル: 現在地点は中央に表示 (既定 On)
      - 現在地点が画面中央に来るよう地図を移動
      - 「現在地点をマーカー表示」も On のときだけ働く
    * トグル: 移動経路を記録 (既定 Off)
      - On でメニューボタンの左に記録開始/停止ボタンを表示
    * 移動経路の統計(経路ごとの地点数・移動距離)を表示
    * ボタン: 読み込み（GPXファイルを移動経路として表示）
    * ボタン: 出力（記録した移動経路をGPXファイルに出力）
    * ボタン: クリア（表示中の移動経路をすべて消去）
    * ボタン: マーカーの設定
    * ボタン: 起動時の画面に戻る

#### 公開データ（ハイキングマップ・通行止め・通行困難地点）

  地図に重ねるハイキングマップは公開API から配信で受け取る(アプリに同梱しない)。
  本アプリは**表示するだけ**で、登録・編集・公開の機能は持たない。

  - データセットは `mapdata`(ポイント・ルート・スポット)と `closures`(通行止め・通行困難)の2本。
    起動時に `GET /api/manifest` で version を先読みし、相違があるときだけ本体を取得する。
    取得内容は Cache API に保持し、オフライン時は前回取得分を表示する。
  - 公開API(`api/` + Vercel Blob)は本リポジトリが提供する。本アプリは GET のみ利用し、
    `POST`(公開)は**外部の運用アプリ**(別リポジトリ)が呼ぶ。
  - API の契約(エンドポイント・認証ヘッダ・応答・公開スキーマ)は
    [公開API 仕様書](docs/publish-api-202609.md)を正本とする(契約バージョン 3.1)。
    検証・応答を変えるときは契約バージョンを更新し、呼び出し側にも反映すること。
