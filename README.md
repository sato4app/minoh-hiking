## minoh-hiking - 箕面でハイキング - ハイキング・ナビ

### 実装機能

#### 初期画面

  - 初期画面(png)を表示
  - 画面の右側中央部に、以下のボタン(textは右寄せ)を縦に並べて表示
    * ハイキングマップ表示
    * ハイキングコース案内・ナビ
    * コース分岐路等のデータ収集
    * 設定
	  - トグル: 詳細データをダウンロード
              Off:z=10～17、On:z=10～18
	  - ボタン: オフライン用地図データをダウンロード
	  - ボタン: ダウンロードした地図データをクリア
    - ボタン: メッセージ履歴を表示

#### 共通機能

  - PWAサポート
  - 地理院地図を初期表示
  - 箕面緊急ポイント(約170点)と公式ハイキングコースを表示
  - オフライン対応用に地理院地図データを事前にダウンロード可能
  - 通行止め・通行困難地点を表示

#### 公開データ(地図データ・通行止め・通行困難地点)

  地図に重ねるデータは公開API から配信で受け取る(アプリに同梱しない)。
  本アプリは**表示するだけ**で、登録・編集・公開の機能は持たない。

  - データセットは `mapdata`(ポイント・ルート・スポット)と `closures`(通行止め・通行困難)の2本。
    起動時に `GET /api/manifest` で version を先読みし、相違があるときだけ本体を取得する。
    取得内容は Cache API に保持し、オフライン時は前回取得分を表示する。
  - 公開API(`api/` + Vercel Blob)は本リポジトリが提供する。本アプリは GET のみ利用し、
    `POST`(公開)は**外部の運用アプリ**(別リポジトリ)が呼ぶ。
  - API の契約(エンドポイント・認証ヘッダ・応答・公開スキーマ)は
    [公開API 仕様書](docs/publish-api-202608.md)を正本とする(契約バージョン 2.0)。
    検証・応答を変えるときは契約バージョンを更新し、呼び出し側にも反映すること。

### 当面実装の対象外

#### ハイキングコースの表示

  - 現在位置の表示

#### ハイキングのコース案内・ナビ

  - コース選択（起点・終点の指定、おすすめコースから選択）

#### コース分岐路等のデータ収集

  - 移動の経路をGPS記録
  - 経路や写真は、スマホ(indexedDB)に一時的に保存
  - 保存データはcloud databaseに保存
