# 箕面ハイキングマップ — アプリ紹介

**バージョン:** 2026.2 ／ **最終更新日:** 2026年8月18日 ／ **対象:** ご利用いただく皆さま

---

## どんなアプリ？

箕面エリアの **国土地理院地図をオフラインで使える** 地図アプリです。
山に入る前に地図を端末へ保存しておけば、**電波の届かない場所でも地図と現在地を確認**できます。
インストール不要で、Webブラウザからそのまま使えます。

> `https://minoh-hiking.vercel.app/`

---

## 主な機能

| 機能 | できること |
|------|-----------|
| **オフライン地図** | 箕面エリアの地図（ズーム14〜18）を端末に保存。電波がなくても地図が表示されます（全部で20MB弱） |
| **ハイキング情報の表示** | 緊急ポイント（167か所）・ハイキングルート（292本）・スポット（209か所）を地図に重ねて表示。タップすると名称や番号が見られます |
| **通行止め・通行困難地点** | 通れない場所（赤い✖）・通りにくい場所（橙の三角）を地図に表示。理由や更新日も確認できます |
| **現在地の表示** | 青い丸で現在地を表示し、地図が自動で追従。位置の精度（誤差の目安）も数秒間表示されます |
| **移動経路の記録** | 歩いた道を線で記録。地点数と移動距離をその場で確認できます。経路は何本でも重ねて記録できます |
| **GPXファイルの出力・読み込み** | 記録した経路を GPX 形式で保存。他の地図アプリでも開けます。保存したファイルを読み込んで地図に戻せます |
| **見た目のカスタマイズ** | マーカーの色・形・大きさを種類ごとに変更できます |
| **日本語／English** | 画面の表示言語を切り替えられます |
| **自動の更新案内** | 地図やアプリが新しくなると、画面上でお知らせします |

## 使いはじめの3ステップ

1. **地図をダウンロード**（電波のある場所で）
   ホーム画面 →「地図のダウンロード」→「ダウンロード」。細かい地図まで欲しいときは
   「詳細地図(z=18)を含む」をオンに。
   このとき、緊急ポイント・ルート・スポット・通行止めの情報もあわせて受け取ります。
2. **地図を開く**
   ホーム画面 →「ハイキングマップ表示」。位置情報の利用を「許可」すると現在地が表示されます。
3. **歩いた経路を記録する**（任意）
   右上のメニュー（≡）→「移動経路を記録」をオン → 画面右上の **▶** で開始、**■** で停止。

> スマホのブラウザメニューから「ホーム画面に追加」を選ぶと、通常のアプリのように全画面で起動できます。

## 移動経路の記録について

- 約20m 歩くか、約1分ごとに地点を記録します。記録した地点の先から現在地までも線でつながるので、
  経路が途切れて見えることはありません。
- 出発地点は **四角**、現在地は **進行方向を向いた三角** で表示されます。
- **経路は何本でも重ねられます。** すでに経路が表示されているときに記録を始める（または GPX を
  読み込む）と、**クリア／追加／キャンセル** を選ぶ画面が出ます。「追加」を選ぶと
  `経路 1` `経路 2` … として別々に残り、経路ごとに地点数と移動距離が表示されます。
  経路ごとに開始マーカーと終了マーカーが付きます。
- 記録中は画面が消えないようにしています（画面が消えると位置の取得が止まるため）。
  電池の消耗が増えるので、終わったら停止してください。
- ホーム画面に戻っても記録は続きます。止まるのは **■** を押したときだけです。
- 記録はアプリ内には保存されません。残したいときは **「出力」で GPX ファイルに保存**してください
  （保存したファイルは「読み込み」で地図に戻せます）。

## 動作環境

- スマートフォン／PC の最新Webブラウザ（Chrome、Safari、Firefox など）
- 現在地表示とオフライン機能には `https://` のページであることが必要です
- 地図の保存容量: 標準範囲（ズーム14〜17・424枚）で約5MB、詳細地図（ズーム18）まで含めると20MB弱が目安です

---

## ご利用にあたって

- 地図・ルートの情報は参考情報です。実際の現地の状況・標識・案内を優先してください。
- 緊急ポイント・ルート・スポット・通行止めの情報は、**電波のある場所でアプリを開いたとき**に
  最新へ更新されます。山中では最後に取得した内容が表示されます。登山口など電波のある場所で
  一度開き直すと確実です。
- **はじめてお使いのときは、電波のある場所で一度開いてください。** 一度も開いていない端末では、
  これらの情報は表示されません（地図タイルも同様です）。
- 位置情報は端末内で地図表示・経路記録に使うだけで、外部へ送信・保存されることはありません。
