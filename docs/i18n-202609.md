**バージョン:** 2026.03
**最終更新日:** 2026年9月24日

## 1. この文書について

画面に出る文言の**日本語と英語を並べた一覧**。翻訳の抜けや、日英で食い違う言い回しを
見つけるための参照用で、**文言の正本はソースの側**にある。直すときはソースを直し、
本書は作り直す（本書を直しても画面は変わらない）。

| 区分 | 正本 | 本書の該当箇所 |
|------|------|----------------|
| UI文言 | `public/i18n.js` の `DICT` | [2章](#2-ui文言i18njs) |
| ご利用の注意とよくある質問 | `public/faq-text.js` | [3章](#3-ご利用の注意とよくある質問faq-textjs) |
| 上記2つの見出し等 | `public/faq.js`（直書き） | [3.3](#33-見出し前置きfaqjs) |

- **英語が無い項目は日本語のまま表示される**（`t()` / `faq.js` の `pick()` のフォールバック）。
  → [5章](#5-集計と英語が無い項目)
- **意図して翻訳しない項目**（「設定・情報/Settings & Info」、クレジットの担当など）は [4章](#4-翻訳対象外の項目)。
- 文中の `{...}` は値の差し込み位置（例: `{points}` は記録地点数）。改行は `<br>` で示す。
- 章立てと並び順は `i18n.js` の節（`// ----- ○○ -----`）に合わせている。
- **英語の大文字・小文字と綴り**:
  - 画面上の名前（ボタン・トグル・項目名・見出し・マーカー種別名）は各語の頭を大文字にする（例: Stop Recording）。
    a / an / the / and / or / to / of / in / on / for などの短い語は、先頭以外は小文字のまま（例: Back to Start Screen）。
  - 文章（メッセージ・確認・説明・注記・状態を表す値・読み上げ専用の aria-label）は文頭だけ大文字にする（例: Track recording started）。
  - 文中で画面上の名前を引用するときは、画面の表記どおりにする（例: Turn on "Record Track"）。
  - 綴りはアメリカ式にそろえる（color / centered / meters）。
