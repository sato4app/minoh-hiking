# 箕面ハイキングマップ 利用者の手引

**バージョン:** 2026.18
**最終更新日:** 2026年9月6日

---

## 1. このアプリについて

「箕面ハイキングマップ」は、箕面エリアの国土地理院地図を **オフラインでも閲覧できる** 地図アプリ
（PWA）です。事前に地図を端末にダウンロードしておけば、電波の届かない山の中でも地図と現在地を
確認できます。緊急ポイントやハイキングルート・スポット、通行止め・通行困難地点も地図に重ねて
表示され、歩いた移動経路を記録して GPX ファイルに出力することもできます。

### 動作環境
- スマートフォン／PCの最新Webブラウザ（Chrome、Safari、Firefox など）
- 現在地表示・オフライン機能を使うには、`https://` のページである必要があります。
- **はじめてお使いのときは、電波のある場所で一度開いてください。** 緊急ポイント・ルート・
  スポット・通行止めの情報は、開いたときにインターネットから受け取ります（一度受け取れば、
  次からはオフラインでも表示されます）。

> **うまく動かないとき・表示の精度が気になるときは**、アプリの「**設定/Settings**」を開き、
> 「**ご利用の注意とよくある質問**」をオンにしてください。現在地やルートのずれ、オフラインでの
> 表示、電池のことなどをまとめています（→第8章）。

### アプリのインストール（ホーム画面に追加）
ブラウザのメニューから「ホーム画面に追加」「アプリをインストール」を選ぶと、通常のアプリのように
全画面で起動できます。

---

## 2. 画面の構成

起動すると **ホーム画面** が表示されます。次のメニューがあります。

| メニュー | 内容 |
|----------|------|
| ハイキングマップ表示 | 地図に緊急ポイント・ルート・通行止め地点・現在地などを表示します（→第4章） |
| 地図データのダウンロード | オフラインで使う地図データを端末に保存します（→第3章） |
| バージョン情報 | 地図・アプリのバージョンやデータ件数を表示します（→第7章） |
| 設定/Settings | 時刻表示・メッセージ履歴・マーカーの設定・言語の設定をまとめています（→第8章） |
| 使い方 | アプリの使い方を1ページずつご案内します（→第10章） |
| QR | いま開いているページのQRコードを表示します（→第9章） |

各画面右下には、**ズームボタン（＋／−）**、**現在のズームレベル（z=NN）**、**スケール**、
**国土地理院クレジット** が表示されます。

> 「設定/Settings」は日本語と英語を併記しています。英語表示のまま使い方が分からなくなっても、
> このボタンから言語を日本語に戻せます。

> 地図に重ねて表示される情報（緊急ポイント・ルート・スポット・通行止め）は、公開された内容が
> そのまま表示されるだけで、特別な操作は不要です。データを**登録・公開する担当者**の方は、
> 専用の運用アプリをお使いください（このアプリからの登録・公開はできません）。

## 3. はじめに：地図データをダウンロードする（オフライン準備）

山に入る前に、**電波のある場所で** 地図データをダウンロードしておきましょう。

1. ホーム画面で「**地図データのダウンロード**」を選びます。
2. 「**詳細地図データ(Z=18)を含む**」のスイッチを選びます。
   - **オフ（初期値）:** 標準的な範囲（ズーム14〜17）。**約 8.5 MB** です。
   - **オン:** より細かい地図（ズーム18）まで含みます。**合計 約 14.1 MB** になります。
3. 「**ダウンロード**」を押すと開始します。進捗が画面に表示されます。
4. 「ダウンロード完了」と表示されれば準備完了です。

### 画面に表示される情報
- **端末の地図データ ⇒ 配信中の最新**: 端末に保存されている地図データの版と、配信されている
  最新の版です。まだ保存していないときは「未ダウンロード」、最新のときは「2026.01（最新）」の
  ように表示されます。新しい版があるときは色が変わります。
- **サイズ**: スイッチで選んだ内容の目安サイズです。「合計 約 14.1 MB」のように表示され、
  すでに端末にある分を除いた不足分がある場合は「更新分 約 5.6 MB」も並びます
  （すべて保存済みのときは「更新分 なし」）。表示は目安のため「約」を付けています。

### 地図を消したいとき
「**クリア**」を押すと、ダウンロード済みの地図をすべて削除します（確認が表示されます）。
空き容量を増やしたいときに使います。

> **ヒント:** ダウンロード中に通信が切れると、一部のタイルが失敗することがあります。電波の良い
> 場所で実行してください。失敗しても、後から「差分のみ更新」で不足分だけ追加できます。

## 4. 地図を見る（ハイキングマップ表示）

ホーム画面で「**ハイキングマップ表示**」を選ぶと、地図に各種情報が重なって表示されます。

### 右上のメニュー（≡）
メニューボタン（≡）を押すと **表示設定パネル** が開きます。地図をタップするとパネルは閉じます。

| 項目 | 内容 |
|------|------|
| 現在地点をマーカー表示 | 現在地（青い丸）を表示します（最初からオン・→第5章） |
| 現在地点は中央に表示 | 地図を現在地に合わせて自動で動かします（最初からオン・→第5章）。オンにするとパネルは自動で閉じます |
| 移動経路を記録 | 歩いた移動経路の記録を始めます（→第5章） |
| 地点数・移動距離 | 経路ごとの地点数と移動距離(km)を表で表示します（→5.3） |
| 読み込み | GPX ファイルの移動経路を地図に表示します（→5.4） |
| 出力 | 記録した移動経路を GPX ファイルに出力します（→5.5） |
| クリア | 記録した移動経路を消します（→5.6） |
| マーカーの設定 | マーカーの色・形・大きさを変更します（→第6章） |
| 起動時の画面に戻る | ホーム画面に戻ります |

> 「時刻を表示」の切り替えは、ホーム画面の「**設定/Settings**」にあります（→第8章）。
> 緊急ポイント・ハイキングルート・通行止め地点は**常に表示**されます（切り替えスイッチはありません）。

### ポイントやルートの詳細を見る
地図上のマーカーや線をタップすると、名称やポイント番号などの情報が吹き出しで表示されます。

### 通行止め・通行困難地点の表示
通行止め・通行困難地点があると、地図に次のマーカーで表示されます。

| マーカー | 意味 |
|----------|------|
| 赤い✖ | 通行止め |
| 橙色の三角 | 通行困難 |

> マーカーの色・形・大きさは「マーカーの設定」で変更できます（→第6章）。上記は初期設定の見た目です。

マーカーをタップすると、地点名・理由・更新日などが吹き出しで表示されます。安全のため、
通行止め・通行困難の情報を確認してからルートを選びましょう。

> 表示される内容は、電波のある場所でアプリを開いたときに最新へ更新されます。山の中（オフライン）では、
> 最後に取得した内容が表示されます。これは緊急ポイント・ルート・スポットも同じです。

## 5. 現在地と移動経路を記録する

### 5.1 現在地を表示する
ハイキングマップを開くと、現在地の取得が始まります（「**現在地点をマーカー表示**」「**現在地点は
中央に表示**」は最初からオンです）。

- **青い丸** が現在地です。
- 地図は現在地が中央に来るように自動で追従します。
- 画面右下の **現在地点を表示ボタン**（照準のようなアイコン）を押すと、現在地が画面の中央に
  来るように地図が動き、現在地を囲む **薄い青色の円** が表示されます。円は **3秒かけて
  ゆっくり小さくなり**、そのあと消えます。現在地がどこかを一目で確かめたいときに使ってください。
- 初回は位置情報の利用許可を求められます。「許可」を選んでください。

それぞれのスイッチで表示を切り替えられます。

- **現在地点をマーカー表示** … オフにすると青い丸を消します。現在地点を表示ボタンを押したときも、
  このスイッチがオフなら青い丸は出ず、薄い青色の円だけが表示されます。
- **現在地点は中央に表示** … オフにすると地図の自動追従を止め、好きな場所を自由に見られます。
  もう一度オンにすると、現在地が画面の中央に来るように地図が動きます。このときパネルは
  自動的に閉じます（パネルが開いたままだと、中央に来た現在地がパネルの下に隠れて見えないため）。

> スイッチを切り替えた直後は、現在地をとり直している数秒のあいだ青い丸が出ないことが
> あります（前の場所をそのまま表示しないようにしているためです）。

> 位置情報が取得できないとき（許可されていない・対応していない等）は、画面下にメッセージが
> 表示されます。

### 5.2 移動経路を記録する
「移動経路を記録」をオンにすると、**メニューボタン（≡）の左** に操作ボタンが表示されます。

| ボタン | 役割 |
|--------|------|
| ▶（緑） | 記録を開始します |
| ■（赤） | 記録を停止します（記録中に表示されます）。**「停止しますか」の確認**が出ます |

1. **▶ ボタン** を押すと記録が始まります。
   - すでに地図に移動経路が表示されているときは、次の3つを選ぶ画面が出ます。
     | ボタン | 動作 |
     |--------|------|
     | クリアして記録開始 | 表示中の経路を消してから記録します |
     | 追加して記録開始 | 表示中の経路を残し、**新しい経路として追加** で記録します（→5.3） |
     | キャンセル | 記録を始めずに **やめます**（経路はそのまま残ります） |
2. 歩くと、通った道が **線** で地図に描かれます。
   - **記録の間隔:** 直近の地点から **約20m 移動** するか、**約1分** ごとに地点を記録します。
   - 記録した地点の先から現在地までも同じ線でつながるので、経路が途中で途切れて見えることは
     ありません。
   - 出発地点には **開始マーカー（四角）**、現在地には **進行方向を向いた三角マーカー** が
     表示されます。経路を追加すると、**経路ごとに** 開始マーカーと終了マーカーが付きます。
3. **■ ボタン** を押すと「移動経路の記録を停止します。よろしいですか?」と確認が出ます。
   **OK** を選ぶと記録を停止し、記録した地点数と移動距離がメッセージで表示されます。
   **キャンセル** を選ぶと記録はそのまま続きます。
   - ■ はメニューボタン（≡）のすぐ左にあるため、≡ を押すつもりで触れてしまうことがあります。
     確認は、その**誤操作で記録が終わってしまうのを防ぐため**のものです。
   - 「移動経路を記録」をオフにして止めるときも、同じ確認が出ます。

> **記録中は画面が消えないようにします。** 画面が消えると位置の取得が止まり、記録が途切れて
> しまうためです（対応していない端末では、その旨のメッセージが出ますが記録は続きます）。
> 電池の消耗が増えるので、記録が終わったら停止してください。

> **記録が止まった理由はメッセージ履歴で確かめられます。**（「設定」→「メッセージ履歴の表示」）
> - `移動記録を終了しました[記録停止ボタン(■)をタップ]` … ■ を押して止めた
> - `移動記録を終了しました[「移動経路を記録」をオフ]` … スイッチをオフにして止めた
> - `前回の移動記録は停止操作なしで中断されました` … アプリが再読み込み・終了されたため
>   記録が消えた（このときは記録した経路も残りません）
>
> 覚えのない停止が起きたときは、この行を見るとどれが起きたのかが分かります。

> **ホーム画面に戻っても記録は続きます。** 記録が終わるのは、■ ボタンを押して確認に OK と
> 答えたときか、「移動経路を記録」をオフにして OK と答えたときだけです。他のアプリに切り替えると位置の取得が止まる
> ことがありますが、アプリに戻ると記録を再開します。

### 5.3 記録の情報を見る（複数の経路）
表示設定パネルの **地点数・移動距離の表** に、`地点数` と `移動距離(km)` が表示されます
（記録が進むと自動で更新されます）。

経路は **何本でも** 地図に重ねて持てます。記録を追加したり GPX を追加で読み込むと、
経路は `経路 1` `経路 2` … と順番に増えていきます。

- 経路が **1本だけ** のときは、`地点数` と `移動距離` だけを表示します。
- 経路が **2本以上** のときは、行の左に `経路 1` `経路 2` … と番号が付き、**経路ごとに1行** で
  地点数と移動距離を表示します。

> 記録を停止したときのメッセージも、経路が複数あるときは `経路 2: 記録地点 12 点 …` のように
> どの経路の記録かが分かる形で表示されます。

### 5.4 GPX ファイルを読み込む
「**読み込み**」を押すと、GPX ファイルの移動経路を地図に表示できます（以前に「出力」した
ファイルや、他の地図アプリで作ったファイルも読み込めます）。

1. すでに地図に移動経路が表示されているときは、次の3つを選ぶ画面が出ます。

   | ボタン | 動作 |
   |--------|------|
   | クリアして読み込み | 表示中の経路を消してから読み込みます |
   | 追加して読み込み | 表示中の経路を残し、**追加** で読み込みます |
   | キャンセル | 読み込まずに **やめます**（経路はそのまま残ります） |

2. ファイルを選ぶと経路が地図に描かれ、全体が見えるように地図が動きます。
3. ファイルの中に経路が複数（GPX の `trkseg` が複数）ある場合は、**それぞれが別の経路** として
   読み込まれます。

> 記録中は読み込みできません。先に **■ ボタン** で記録を停止してください。

### 5.5 記録した経路を出力する（GPX）
「**出力**」を押すと、記録した移動経路を **GPX ファイル**（他の地図アプリでも開ける形式）として
保存できます。

1. 「出力」を押すと、ファイル名の入力画面が開きます。
2. ファイル名は最初から `日付-連番`（例: `20260725-01`）が入っています。
   日付は記録を始めた日、連番は同じ日に2回目を出力するときは自動で `02` になります。
   - **全体を自由に編集できます**（日付の部分も変更できます）。
   - 入力欄が開いたときは文字は選ばれておらず、カーソルが末尾にあります。
     そのまま続きを打ち足したり、消したりできます。
   - `.gpx` は入力する必要はありません（保存するときに自動で付きます）。
3. 「**出力**」を押すとファイルがダウンロードされます。

> 表示中の経路は **すべて** 1つのファイルに出力されます。経路ごとの区切りも保存されるので、
> 出力したファイルを読み込み直すと同じ経路の並びに戻ります。

> 記録がないときは「出力する移動経路がありません」と表示されます。

### 5.6 記録を消す
「**クリア**」を押すと、表示中の移動経路を **すべて**（複数ある場合も全部）消します
（確認が表示されます）。

> **注意:** スイッチをオフにしたりホーム画面に戻っても、記録した経路はすぐには消えません。
> 完全に消したいときは「クリア」を使ってください。
> なお、記録はアプリを再読み込みすると失われます。残しておきたいときは、消す前に
> 「出力」で GPX ファイルに保存してください。

## 6. マーカーの見た目を変える

「マーカーの設定」では、地図上の目印（マーカー）の **色・形・大きさ** を種類ごとに変更できます。
ハイキングマップ表示のマップ画面メニュー（≡）、またはホーム画面の「設定/Settings」から開けます。

### 設定できる種類
緊急ポイント／ハイキングルート／スポット／通行止め地点／通行困難地点／
移動記録開始点／移動記録現在地点／移動記録経路

### 操作方法
- **色:** カラーパレットから選びます。
- **形:** 円・四角・三角・ひし形・星・線・✖ から選びます。
- **大きさ:** 数値（1〜50）で指定します。

変更はすぐに地図と次回起動時に反映されます。元に戻したいときは「**規定値に戻す**」を押します。

## 7. バージョン情報

ホーム画面の「**バージョン情報**」では、次の内容を確認できます。

| 項目 | 内容 |
|------|------|
| 起動時にアプリの更新版を確認 | オンにすると、起動時に新しいアプリがあるか確認します |
| アプリバージョン | アプリ本体（画面・機能、ハイキングルート等を含む）のバージョン |
| 国土地理院地図タイル | ダウンロード対象の地図タイルのバージョン |
| ハイキングマップ | いま表示している緊急ポイント・ルート・スポットのバージョン |
| 通行止め・通行困難地点 | いま表示している通行止めデータのバージョン |
| データ件数 | **ポイント・ルート・スポット・通行止め** の件数 |

この画面を開いたとき、新しい地図やアプリがあれば更新のご案内が表示されます（→第11章）。

## 8. 設定/Settings

ホーム画面の「**設定/Settings**」では、表示や動作の設定をまとめて行えます。

| 項目 | 内容 |
|------|------|
| 時刻を表示 | 地図画面に現在時刻（時:分）を表示します（最初からオン） |
| ズームレベルを表示 | 地図画面の右下に現在のズーム（`z=NN`）を表示します（最初からオン） |
| ご利用の注意とよくある質問 | ルートや現在地のずれ、通行止めの見方など、**山に入る前に知っておいていただきたいこと**（9項目）と、よくある質問（27問）を表示します |
| メッセージ履歴の表示 | これまでの記録（起動時の確認、ダウンロード、移動記録など）を新しい順に表示。ゴミ箱アイコンで全消去できます |
| このアプリについて | アプリ名・URL・contributors（アプリ企画・開発／マップのデータ構築／プロジェクト推進の担当者）を表示します |
| マーカーの設定 | マーカーの色・形・大きさを変更します（→第6章） |
| 言語の設定/Language Settings | 表示する言語を選びます（日本語／English、最初は日本語） |

- 「ご利用の注意とよくある質問」「メッセージ履歴の表示」「このアプリについて」は、スイッチで
  内容の表示・非表示を切り替えられます。**この3つは、設定を開き直すたびに必ずオフに戻ります。**
- 言語を選ぶと画面が読み込み直され、選んだ言語で表示されます（読み込み後はこの設定画面が
  開いた状態に戻ります）。
  ※ 地図上の地名やポイント名などは日本語のままです。

## 9. QRコードで知らせる

ホーム画面の「**QR**」を押すと、いま開いているページの **QRコード** が表示されます。
一緒に歩く人にカメラで読み取ってもらうと、その人の端末でも同じページを開けます。

- QRコードの下には、読み取り先のアドレス（URL）も文字で表示されます。
- QRコードはアプリの中で作っているため、**電波が届かない場所でも表示できます**。
  ただし、読み取った相手がそのページを開くには通信が必要です。
- 閉じるときは、右上の **×** を押すか、QRコードの外側をタップします。

## 10. 使い方ガイド

ホーム画面の「**使い方**」を押すと、このアプリの使い方を **1ページずつ順番に** ご案内します。
画面が暗くなり、**説明している場所だけが明るく残る** ので、どこの話をしているのかが一目で分かります。

**はじめて開いたときは自動で表示されます。** 途中で閉じても、次回からは自動では出ません。
もう一度見たいときは、いつでも「使い方」から開けます。

### 操作のしかた
| ボタン | 動作 |
|--------|------|
| 次へ | 次のページへ進みます（最後のページでは「終わり」になり、押すと閉じます） |
| 戻る | 前のページへ戻ります（1ページ目では押せません） |
| 閉じる | 途中でやめます |

> パソコンでは、**→** キーで次へ、**←** キーで戻る、**Esc** キーで閉じることもできます。

### ご案内する内容（全11ページ）

| # | 内容 |
|---|------|
| 1 | このアプリでできること |
| 2 | ハイキングマップ表示（→第4章） |
| 3 | 地図データのダウンロード（→第3章） |
| 4 | バージョン情報（→第7章） |
| 5 | 設定/Settings（→第8章） |
| 6 | 使い方 と QR（→本章・第9章） |
| 7 | 地図に表示される情報（→第4章） |
| 8 | 画面の右下（縮尺・ズーム・現在地点表示ボタン）（→5.1） |

7ページ目からは **ハイキングマップ表示に自動で切り替わり**、実際の画面を見ながらご案内します。
このとき、はじめてお使いの端末では位置情報の利用許可を尋ねられます。「許可」を選んでください

> （ページごとに画面が切り替わるため、途中で操作されると説明と食い違ってしまいます）。
> 実際に試すときは「閉じる」で案内を終えてから操作してください。

## 11. アプリ・地図を最新にする

### 地図の更新
地図データ（タイル）が新しくなると、画面上部に **更新バナー** が表示されます。

- 「**差分のみ更新**」… まだ持っていない地図だけを追加でダウンロードします（おすすめ）。
- 「**すべて更新**」… すべての地図を取り直します。
- 「**後で**」「×」… バナーを閉じます（後で更新できます）。

「バージョン情報」を開いたときにも、新しい地図があれば「地図データのダウンロード」からの更新を
ご案内します。

### アプリの更新
アプリ本体に新しい版があると、起動時または「バージョン情報」を開いたときに、更新するか尋ねる
メッセージが表示されます。「OK」を選ぶとアプリが最新になり、自動的に再読み込みされます。
（ダウンロード済みの地図は消えません。）

## 12. 用語

| 用語 | 意味 |
|------|------|
| タイル | 地図を小さな正方形に分割した画像。これを集めて地図が表示されます |
| オフライン地図 | 端末に保存した地図。電波がなくても表示できます |
| ルート | ハイキングの個別区間（線）。複数のルートをまとめた「コース」は今後対応予定です |
| スポット | ルート沿いの見どころなどの地点 |
| 通行止め・通行困難地点 | 通れない・通りにくい場所の目印（初期設定: 赤✖＝通行止め、橙三角＝通行困難） |
| 移動記録（移動経路） | あなたが実際に歩いた経路の記録 |
| GPX | 移動経路を保存する標準的なファイル形式。他の地図アプリでも開けます |
| PWA | Webサイトをアプリのように使える仕組み。ホーム画面に追加して全画面で使えます |
