# 箕面ハイキングマップ 利用者の手引

**バージョン:** 2026.3
**最終更新日:** 2026年7月18日

---

## 1. このアプリについて

「箕面ハイキングマップ」は、箕面エリアの国土地理院地図を **オフラインでも閲覧できる** 地図アプリ
（PWA）です。事前に地図を端末にダウンロードしておけば、電波の届かない山の中でも地図と現在地を
確認できます。緊急ポイントやハイキングルート・スポット、通行止め・通行困難地点も地図に重ねて
表示され、歩いた移動経路を記録することもできます。

### 動作環境
- スマートフォン／PCの最新Webブラウザ（Chrome、Safari、Firefox など）
- 現在地表示・オフライン機能を使うには、`https://` のページである必要があります。

### アプリのインストール（ホーム画面に追加）
ブラウザのメニューから「ホーム画面に追加」「アプリをインストール」を選ぶと、通常のアプリのように
全画面で起動できます。

---

## 2. 画面の構成

起動すると **ホーム画面** が表示されます。次のメニューがあります。

| メニュー | 内容 |
|----------|------|
| ハイキングマップ表示 | 地図に緊急ポイント・ルート・通行止め地点・現在地などを表示します |
| 地図のダウンロード（オフライン用） | 地図を端末に保存します |
| 設定と情報 | マーカーなどの設定と、バージョンやメッセージ履歴などの情報をまとめて表示します |

各画面右下には、**ズームボタン（＋／−）**、**現在のズームレベル（z=NN）**、**スケール**、
**国土地理院クレジット** が表示されます。

> 通行止め・通行困難地点を**登録・公開する担当者**の方は、専用のリンク（`?closure=true` 付き）で
> 起動したときだけ「通行止め・通行困難地点」ボタンが表示されます。操作手順は
> [運用手順書 `closures-operations-202607.md`](closures-operations-202607.md) を参照してください。
> 一般の利用者は、公開された通行止め地点が地図に表示されるだけで、特別な操作は不要です。

## 3. はじめに：地図をダウンロードする（オフライン準備）

山に入る前に、**電波のある場所で** 地図をダウンロードしておきましょう。

1. ホーム画面で「**地図のダウンロード（オフライン用）**」を選びます。
2. 「**詳細地図(z=18)を含む**」のスイッチを選びます。
   - **オフ:** 標準的な範囲（ズーム14〜17）。データ量が小さくて済みます。
   - **オン:** より細かい地図（ズーム18）まで含みます。データ量は大きくなります。
3. 「**ダウンロード**」を押すと開始します。進捗が画面に表示されます。
4. 「ダウンロード完了」と表示されれば準備完了です。

### ダウンロード済みの情報
モーダル上部に、**ダウンロード済み地図バージョン** と **ファイルサイズ(MB)** が表示されます。

### 地図を消したいとき
「**クリア**」を押すと、ダウンロード済みの地図をすべて削除します（確認が表示されます）。
空き容量を増やしたいときに使います。

> **ヒント:** ダウンロード中に通信が切れると、一部のタイルが失敗することがあります。電波の良い
> 場所で実行してください。失敗しても、後から「差分のみ更新」で不足分だけ追加できます。

## 4. 地図を見る（ハイキングマップ表示）

ホーム画面で「**ハイキングマップ表示**」を選ぶと、地図に各種情報が重なって表示されます。

### 右上のメニュー（≡）
メニューボタン（≡）を押すと **表示設定パネル** が開きます。地図をタップするとパネルは閉じます。

| 項目 | 内容 |
|------|------|
| 現在地点をマーカー表示 | 現在地（青い丸）を表示します（最初からオン・→第5章） |
| 現在地点は中央に表示 | 地図を現在地に合わせて自動で動かします（最初からオン・→第5章） |
| 移動経路を記録 | 歩いた移動経路の記録を始めます（→第5章） |
| サイズ／クリア | 記録した移動経路の情報表示・消去 |
| マーカーの設定 | マーカーの色・形・大きさを変更します（→第6章） |
| 撮影画像の解像度の設定 | （準備中） |
| 起動時の画面に戻る | ホーム画面に戻ります |

> 「時刻を表示」の切り替えは、ホーム画面の「**設定と情報**」にあります（→第7章）。
> 緊急ポイント・ハイキングルート・通行止め地点は**常に表示**されます（切り替えスイッチはありません）。

### ポイントやルートの詳細を見る
地図上のマーカーや線をタップすると、名称やポイント番号などの情報が吹き出しで表示されます。

### 通行止め・通行困難地点の表示
通行止め・通行困難地点があると、地図に次のマーカーで表示されます。

| マーカー | 意味 |
|----------|------|
| 赤いひし形 | 通行止め |
| 橙色の三角 | 通行困難 |

マーカーをタップすると、地点名・理由・更新日などが吹き出しで表示されます。安全のため、
通行止め・通行困難の情報を確認してからルートを選びましょう。

> 表示される内容は、電波のある場所で地図を開いたときに最新へ更新されます。山の中（オフライン）では、
> 最後に取得した内容が表示されます。

## 5. 現在地と移動経路を記録する

### 5.1 現在地を表示する
ハイキングマップを開くと、現在地の取得が始まります（「**現在地点をマーカー表示**」「**現在地点は
中央に表示**」は最初からオンです）。

- **青い丸** が現在地です。
- 地図を開いたときや「現在地点をマーカー表示」をオンにしたとき、現在地のまわりに **薄い円**（位置の
  精度＝誤差の目安）が **数秒間だけ** 表示され、その後自動的に消えます。
- 地図は現在地が中央に来るように自動で追従します。
- 初回は位置情報の利用許可を求められます。「許可」を選んでください。

それぞれのスイッチで表示を切り替えられます。

- **現在地点をマーカー表示** … オフにすると青い丸を消します。
- **現在地点は中央に表示** … オフにすると地図の自動追従を止め、好きな場所を自由に見られます。

> 位置情報が取得できないとき（許可されていない・対応していない等）は、画面下にメッセージが
> 表示されます。

### 5.2 移動経路を記録する
「移動経路を記録」をオンにすると、メニューボタンの下に操作ボタンが表示されます。

| ボタン | 役割 |
|--------|------|
| ▶（緑） | 記録を開始します |
| ■（赤） | 記録を停止します（記録中に表示されます） |
| カメラ | 写真を撮影します |

1. **▶ ボタン** を押すと記録が始まります。
2. 歩くと、通った道が **線** で地図に描かれます。
   - **記録の間隔:** 直近の地点から **約20m 移動** するか、**約1分** ごとに地点を記録します。
   - 出発地点には **開始マーカー（四角）**、現在地には **進行方向を向いた三角マーカー** が
     表示されます。
3. **■ ボタン** を押すと記録を停止します。停止すると、記録した地点数・写真の枚数・移動距離が
   メッセージで表示されます。

### 5.3 記録の情報を見る・消す
表示設定パネルの下部にあるボタンを使います。

- 「**サイズ**」… 現在の `記録地点 ○点 / 写真 ○枚 / 移動距離 ○km` を表示します。
- 「**クリア**」… 記録した移動経路をすべて消します（確認が表示されます）。

> **注意:** スイッチをオフにしたりホーム画面に戻っても、記録した経路はすぐには消えません。
> 完全に消したいときは「クリア」を使ってください。

### 5.4 写真を撮る（一部機能）
カメラボタンを押すと、端末のカメラ／写真選択が起動します。記録中に撮った写真は枚数として
数えられます。
※ 撮影した写真を保存して地図に表示する機能は、今後のバージョンで対応予定です。

## 6. マーカーの見た目を変える

「マーカーの設定」では、地図上の目印（マーカー）の **色・形・大きさ** を種類ごとに変更できます。
マップ画面メニュー、または「設定と情報」から開けます。

### 設定できる種類
緊急ポイント／ハイキングルート／ルート案内写真／スポット／トラック開始点／トラック現在地点／
トラック／写真撮影場所

### 操作方法
- **色:** カラーパレットから選びます。
- **形:** 円・四角・三角・ひし形・星・線 から選びます。
- **大きさ:** 数値（1〜50）で指定します。

変更はすぐに地図と次回起動時に反映されます。元に戻したいときは「**規定値に戻す**」を押します。

> 通行止め・通行困難地点のマーカー（赤ひし形／橙三角）は決まった見た目で、この設定の対象外です。

## 7. 設定と情報

ホーム画面の「**設定と情報**」では、マーカーなどの設定と、バージョンや履歴などの情報を
まとめて確認できます。**上段が設定、下段が情報**です。

### 設定（上段）
- **マーカーの設定:** マーカーの色・形・大きさを変更します（→第6章）。
- **撮影画像の解像度の設定:** （準備中）

### 情報（下段）
| 項目 | 内容 |
|------|------|
| 時刻を表示 | 地図画面に現在時刻（時:分）を表示します（最初からオン） |
| 起動時にアプリの更新版を確認 | オンにすると、起動時に新しいアプリがあるか確認します |
| バージョン情報 | 地図バージョン・アプリバージョン・通行止め地点のバージョンと、**ポイント・ルート・スポット・通行止めの件数**を表示。新しい版があれば更新を案内します |
| メッセージ履歴の表示 | これまでの記録（起動時の確認、ダウンロード、移動記録など）を新しい順に表示。ゴミ箱アイコンで全消去できます |
| このアプリについて | アプリ名・URL・contributors を表示します |

「バージョン情報」「メッセージ履歴の表示」「このアプリについて」は、スイッチで内容の
表示・非表示を切り替えられます。

## 8. アプリ・地図を最新にする

### 地図の更新
地図データ（タイル）が新しくなると、画面上部に **更新バナー** が表示されます。

- 「**差分のみ更新**」… まだ持っていない地図だけを追加でダウンロードします（おすすめ）。
- 「**すべて更新**」… すべての地図を取り直します。
- 「**後で**」「×」… バナーを閉じます（後で更新できます）。

「設定と情報」→「バージョン情報」を開いたときにも、新しい地図があれば「地図のダウンロード」
からの更新をご案内します。

### アプリの更新
アプリ本体に新しい版があると、起動時または「設定と情報」を開いたときに、更新するか尋ねる
メッセージが表示されます。「OK」を選ぶとアプリが最新になり、自動的に再読み込みされます。
（ダウンロード済みの地図は消えません。）

## 9. 困ったときは（よくある質問）

**Q. 現在地（青い丸）が表示されません。**
A. 表示設定パネルの「現在地点をマーカー表示」がオンか確認してください。また、位置情報の利用を
許可しているか、`https://` のページであるかも確認してください。屋内や谷間では位置の取得に時間が
かかることがあります。

**Q. 現在地のまわりの円（精度の円）がすぐ消えます。**
A. 精度の円は、地図を開いたときや「現在地点をマーカー表示」をオンにしたときに **数秒間だけ**
表示される仕様です。もう一度見たいときは、スイッチを入れ直すか地図を開き直してください。

**Q. オフラインで地図が真っ白（穴あき）になります。**
A. その範囲・ズームの地図がダウンロードされていない可能性があります。電波のある場所で、必要な
範囲をダウンロードしてください。詳細（z=18）まで見たい場合は「詳細地図(z=18)を含む」をオンに
してダウンロードします。

**Q. 通行止め・通行困難のマーカーが古い気がします。**
A. 表示は、電波のある場所で地図を開いたときに最新へ更新されます。登山口など電波のある場所で
一度地図を開き直してください。

**Q. 記録した移動経路が消えてしまいました。**
A. 「クリア」を押すと経路は削除されます。現状、移動経路は端末に保存されず、地図を閉じたり
再読み込みすると失われます（保存機能は今後対応予定）。

**Q. 空き容量が足りないと出ます。**
A. 「地図のダウンロード」画面の「クリア」で不要な地図を削除すると空き容量を増やせます。

**Q. 地図やアプリのバージョンを確認したいです。**
A. 「設定と情報」→「バージョン情報」で、地図バージョン・アプリバージョン・通行止め地点の
バージョンと各データの件数を確認できます。

## 10. 用語

| 用語 | 意味 |
|------|------|
| タイル | 地図を小さな正方形に分割した画像。これを集めて地図が表示されます |
| オフライン地図 | 端末に保存した地図。電波がなくても表示できます |
| ルート | ハイキングの個別区間（線）。複数のルートをまとめた「コース」は今後対応予定です |
| スポット | ルート沿いの見どころなどの地点 |
| 通行止め・通行困難地点 | 通れない・通りにくい場所の目印（赤ひし形＝通行止め、橙三角＝通行困難） |
| トラック（移動経路） | あなたが実際に歩いた経路の記録 |
| PWA | Webサイトをアプリのように使える仕組み。ホーム画面に追加して全画面で使えます |
